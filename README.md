# Base de datos de logística de envíos — Bases de Datos 1

Obligatorio de **Bases de Datos 1** (Universidad ORT, agosto de 2025). Modelo relacional en **SQL Server (T-SQL)** para gestionar envíos: tipos de vehículo, vehículos, choferes y sus habilitaciones, envíos, clientes, paquetes, insumos (con compatibilidades entre ellos) y eventos.

## Contenido

```
sql/
  ddl.sql        Crea la base OBLIGATORIO_BD1_287318 y las tablas
  insert.sql     Datos de prueba
  consultas.sql  Consultas del obligatorio
docs/
  Diagrama_Obligatorio.dia                 Diagrama (se abre con Dia)
  Documentacion_Obligatorio_BD1_287318.docx  Documentación de la entrega
```

## Cómo ejecutarlo

En SQL Server Management Studio (o `sqlcmd`), ejecutá en este orden: `ddl.sql` → `insert.sql` → `consultas.sql`.
